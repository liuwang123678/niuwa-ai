能干活01

十个技能：陪你说说话、把要紧的记下来、联网调研、用浏览器点网页、写代码跑代码、 排错、写测试、做计划、交付前自查，还有女娲。 你说「帮我查一下」，它是真的去查，然后给你带来源的结论——不是凭印象编一段。 你说「写个脚本算一下」，它会写、会存到你指定的地方、会跑起来，把报错自己修完再给你结果。

干活的时候它会说清楚在干什么，不闷头搞半天；做不成就说做不成，说清楚卡在哪。

记得住02

它有一份跨会话的记忆。你提过的偏好、习惯、正在做的事，下次不用再说一遍。 记什么由它自己判断——判断标准是「这条信息两周后、在另一场对话里还有用吗」， 记太多反而会把重点淹掉。

错的做法是像念档案一样复述。所以它只会顺口问一句「今天还熬夜吗」。

随身带着的

十个技能

  1. companion-talk 陪伴对话
    先分清你要的是解决还是被听见。「怎么才能早睡」和「我又熬夜了，烦死了」是两件事，回的也该是两种。
  2. note-taking 记忆
    把对话里值得长期留住的挑出来存下：偏好、习惯、身份、计划、重要日期。你明确说「记住这个」它也照办。
  3. web-research 联网调研
    问的是训练数据里没有、或者可能过时的东西时走这条。给结论也给出处，不给你一段听着很像真的话。
  4. browser-task 浏览器
    打开网页、找到元素、点击、填表、翻页。看一步、想一步、做一步、再看一步——真的在页面上动手。
  5. coding 写代码
    写一段、跑起来、读报错、改一改、再跑——这个循环它自己走。跑在你自己的电脑上， 用的是你真装了的 Python 和 Node。手机上只能跑 JavaScript，跑不了 Python，这一条它自己会说清楚。
  6. debugging 排错
    出错时先复现，把原始报错读一遍，再用搜索缩小范围。一次只改一个地方，改根因不打补丁。 不许为了让测试变绿去改测试。
  7. testing 写测试
    先把「怎么算对」写成一条现在会失败的测试，再写最小的实现让它通过。没红过的测试不算数， mock 掉正要验的那一层也不算。
  8. planning 做计划
    要动三个以上文件、或者步骤多到容易漏时，先摸清现状，再列一份每一步都带验收标准的计划。 做到一半路不通会停下来告诉你，不默默换路。
  9. review 交付前自查
    需求逐条对、改动范围有没有超、错误路径处理了吗、测试真跑了吗、能不能回滚。区分「验证过」和「看着对」。
  10. nuwa 女娲
    输入一个人名，它去调研并提炼出那个人的思维框架，生成一个能直接拿来用的技能。不是复制一个人，是把他的认知方式写成一套能跑的东西。

同一件事不留两版03

你说过的话改了口，它更新原来那条，不会攒出两条互相打脸的记忆。 有几条看着像又拿不准是不是一回事的时候，它会指给你看，由你决定合不合。
